🚀 Featured Projects

🔍 "Basic Network Sniffer" (https://github.com/Devkaiz/Basic_Network_Sniffer)

A Python-based network packet sniffer using Scapy to capture and analyze network traffic.

- Displays source and destination IP addresses.
- Identifies common protocols such as TCP, UDP, and ICMP.
- Shows port numbers, packet lengths, timestamps, and packet structure.
- Provides a limited hexadecimal preview of available payload data.

Technologies: Python, Scapy, Npcap

🛡️ "ML-Based Network Intrusion Detector" (https://github.com/Devkaiz/ML-Based-Network-Intrusion-Detector)

A machine learning project that classifies network traffic as benign or DDoS using a Random Forest classifier.

- Uses the CIC-IDS2017 dataset.
- Applies data preprocessing and feature-based classification.
- Evaluates model performance using accuracy and a confusion matrix.

Technologies: Python, Pandas, Scikit-learn, Random Forest, CIC-IDS2017

🦯 ClearPath — AI-Powered Assistive Navigation

An assistive navigation project designed to help visually impaired individuals identify obstacles and navigate their surroundings.

- Explores computer vision for object detection.
- Aims to provide audio-based environmental feedback.
- Focuses on accessible and assistive technology.

Technologies: Python, YOLOv5, OpenCV, Text-to-Speech
